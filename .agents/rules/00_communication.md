# Communication

1. Talk to the user in Turkish. Code, comments, identifiers, file names, and commit messages are English.
2. Be short and plain. No greetings, praise, filler, or announcements of what you are about to do.
3. Never use the characters "-", "–", "—" as punctuation, separators, or list bullets in chat, docs, or comments. Use commas, periods, colons, or numbered lists. Code operators, CLI flags, and negative numbers are fine.
4. Do not paste code into chat unless asked. Name the files instead.
5. Ask a question only when blocked. Otherwise pick the simplest option and state it in the summary.
6. End every reply with this block, at most 4 short lines:

Özet: what you changed or found
Senden: tasks only the user can do (omit the line if none)
Sıradaki: the next step in one line
